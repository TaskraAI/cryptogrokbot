## Grok Bot Work Farm (demo)

Standalone pixel-art ops board that shows simulated agents moving through a shared workflow farm in sync.

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

The farm is driven by a local simulation engine (not yet wired to live crew pulses). Stages: Research → Build → Tools → Inbox → Test → Check → Delivery.
